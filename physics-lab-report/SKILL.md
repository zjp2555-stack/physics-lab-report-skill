# 大学物理实验报告写作

为山东大学（威海）普通物理实验课产出两类输出：**模式一·实验预习**与**模式二·数据处理与结论**。所有规范已内建于本技能的 references，依据是本课程误差理论课件、评分标准与已批阅的样例报告。全文用中文书写。

## 第零步：读反馈记录（每次必做）

被调用后、动笔前，先读本技能目录下的 `references\反馈记录.md`。其中已确认的纠正与偏好**优先于本文件和 references 的默认写法**：与本实验相关的条目直接照办；与本次实验无关的条目也不要违反，除非该条目明显不适用。反馈记录不存在或为空表，则按默认规范继续。

## 第一步：查实验讲义库（点名实验时必做）

用户提到具体实验名称时，先读 `references\讲义\索引.md` 查有无该实验的讲义文件（目前收录普通物理实验 5 个、综合实验 20 个）。命中则读该文件全文——它是该实验**目的、仪器、原理、步骤、注意事项、数据处理要求、思考题**的第一依据，优先于通用模板与教材常识；文件里标"讲义未给出"的项按 `references\01` 通用规范补齐并在输出中说明；第九节列出的讲义印刷疑误采用加注后的修正形式。未命中则按通用模板写，并提醒用户可提供讲义补入库。误差计算规范始终按 `references\01`，报告格式始终按 `references\02`、`03`。

## 模式判定

- 用户只给实验课题、未给测量数据 → **模式一（实验预习）**。
- 用户给实验课题 + 测量数据，要求处理数据或给结论 → **模式二（数据处理与结论）**。"给课题+数据求处理"只走模式二，不先写预习。
- 用户明确同时要求两类输出（如"先写预习报告，再把这组数据处理了"）→ 先完整输出模式一，再对给定数据输出模式二，两段各自满足本模式的节次要求。
- 无法判断时问一句再动手，不要猜。

## 输出格式的硬性约定（两种模式通用，用户已定型）

**按报告纸固定表单的编号节次组织输出，全部用 Markdown 结构呈现，禁止纯文本堆叠：**

- 标题行 `# 实验名称：×××`；节次用二级标题按报告纸节次编号与名称书写：**一、实验目的　二、实验仪器　三、实验原理　四、实验步骤及操作要点　五、数据处理及实验结论　六、思考及讨论题　七、原始数据记录**。
- **预习模式只完成前四节**；**数据处理模式完成五、七两节**（五内含数据记录→数据处理→误差分析→实验结论，误差分析不单设节号；七为整理后的原始数据表，表上方注精度/零点/环境）；六、思考及讨论题仅在用户明确要求时作答，以同样的节次格式追加在固定节次之后（格式见 references\03 §2.9）。
- 原理内小节用三级标题 `### 1. ×××`；步骤用有序列表，每步的①②③子动作用无序子列表分行，"要点"另起一行；注意事项、误差分析用列表；数据表用 Markdown 表格。
- 公式一律用 LaTeX：行内符号用 `$…$`（如 $D_1$、$\Delta_{\text{仪}}$，`\text{}` 可包中文）；显示公式用 `$$ … $$` 单独成段、前后空行；**`\tag{n}` 不可用**（渲染为乱码源码），公式编号写在公式前的引导句里（如"……即式 (3)："），正文引用写"由式 (4)"。
- 预习模式不输出长篇操作类表格（如旋钮预置表、校准位置表这类两三列的操作表格）：此类信息写成步骤条目内嵌的紧凑文字（"旋钮→位置"逐项在动作句里）。
- 思考题回答要简短：每题 1~3 句，直接给结论 + 关键公式/数值比较，不写铺垫和过程复述。

## 模式一：实验预习

输入 = 实验课题（+ 用户能提供的材料，如教材章节、仪器清单）。仪器型号、量程等细节不确定时写通用名称并注明"以实验室实际配备为准"，不要编造具体型号。

先读：`references\01-误差理论与数据处理规范.md` §3（原理里要预告不确定度传递公式）、`references\02-评分要求与格式规范.md` §2（预习报告清单）、`references\03-报告范例与句式.md` §一（结构与标签对应）、§二 2.1~2.4 与 2.10（各部分句式、表格样式）；套整体结构时看 §三的同类骨架。

输出按报告纸节次完成前四节，各节写法（定型于反馈记录）：

| 节次 | 写什么 |
|---|---|
| `# 实验名称：×××` | 实验题目全称作一级标题 |
| 一、实验目的 | 2~3 条，动词开头（了解/掌握/学习/测定/观察/验证），每条一句话 |
| 二、实验仪器 | **完全照抄用户当次调用时所给资料里的仪器清单原文，不做任何增删改**：不加型号/量程/分度等补充、不加括注、不加"以实验室实际配备为准"类备注；只写清单，不写仪器构造细节 |
| 三、实验原理 | **篇幅 ≤600 字**：分小标题（`### 1. ×××`）按物理概念切块，文字叙述与编号公式交替推进；写清关键公式，**必须包含后续数据处理要用的不确定度传递公式**（评分要求原理完整，数据处理时直接取用）；面板与操作细节归步骤节，不写进原理；**不输出**装置图/电路图/光路图的"文字画法说明"段落（装置结构在正文叙述中说清） |
| 四、实验步骤及操作要点 | **篇幅 ≤600 字**（与原理同限）。可执行的编号步骤：外层 1.2.3. 按阶段分块，内层 ①②③ 列具体动作（祈使短句，含"重复测量 N 次"等可执行动作）；每阶段的易错点与读数规范（估读到最小刻度的 1/10 或 1/2、扣除零点读数、防空程、待稳定后再读数、单方向计数防漏数等）以"要点：…"嵌在该阶段末尾；跨阶段通用要点在末尾以"注意事项：①②③…"单列 |

预习模式**不输出"数据记录表格"**（数据记录在预习阶段不作答；誊写时原始数据表留待报告纸"七、原始数据记录"）。

质量要求（对应评分标准，违反会扣分）：
- **自行组织语言，严禁照抄课本**——完全照抄书本扣 0.5 分。原理用自己的话串讲，不出现课本原句式。
- 要素完整：实验目的、实验原理、电路图/光路图等必备要素缺一不可；内容缺失、条理不清酌情减分。
- 简明扼要：预习报告写原理与操作要点，不展开思考题答案。

### 模式一输出示例（节选，示意格式与深度）

```
# 实验名称：牛顿环

## 一、实验目的
1. 通过对牛顿环干涉现象的观测，加深对光的波动性的认识。
2. 掌握用牛顿环测量透镜曲率半径的方法。
3. 学习用逐差法处理数据。

## 三、实验原理
### 1. 牛顿环装置与光路
把一块曲率半径很大的平凸透镜的凸面置于平板玻璃上，两者之间形成厚度不均匀的空气薄膜层。……
暗环条件 2e = kλ（k=0,1,2,…；环心 e=0 处 δ=λ/2，为暗斑），即式 (1)：$$2e = k\lambda$$
曲率半径公式为式 (5)：$$R = \frac{D_m^2 - D_n^2}{4(m-n)\lambda}$$（后续不确定度评定即对此式取对数求导）

## 四、实验步骤及操作要点
1. **调节牛顿环仪**
   - ①…②…③…

   要点：…
2. **测量**
   - ①沿同一方向移动测微鼓轮防回程…②从中心向一侧数至第 m 环，逐环记录位置读数…③重复测量。
```

## 模式二：数据处理与结论

输入 = 实验课题 + 实验测量数据。

先读：`references\01-误差理论与数据处理规范.md` 全文精读（§2 有效数字与修约、§3 不确定度评定与传递、§4 数据处理方法、§5 仪器允差）、`references\02-评分要求与格式规范.md` §4（数据处理清单）、`references\03-报告范例与句式.md` §二 2.5~2.9（2.5 数据处理三范式——含"逐差型实验必须补 B 类评定并合成"的强制注、2.6 结果表示写法、2.7 误差分析句式、2.8 结论句式、2.9 思考题格式）；需要套整体结构时再看 §三的同类骨架。

**收到数据先审核、后计算（用户定型流程）**：用户记录表中已填的派生量（平均值、修正值、u_A、u_B、U_合等）逐项对照规范核验——u_B 对照 references\01 §5 允差表、平均值用原始读数复算、修约对照 §2——先输出"数据审核清单"逐项标注 ✓/✗ 与依据；有 ✗ 项时指出错误并给出正确值，经用户确认修改后再进入计算链。原始读数无法代用户验证，誊写时提请用户抽查认读是否有误。审核中发现的涂改与取值疑点**只在对话里向用户指出并确认**，报告正文按确认后的取值直接计算，不出现"曾涂改""按自洽链取值"这类个人修正过程的叙述。

输出五、七两节（六按需），各节写法（定型于反馈记录）：

| 节次 | 写什么 |
|---|---|
| `# 实验名称：×××` | 实验题目全称作一级标题（与模式一同名） |
| 五、数据处理及实验结论 | 内含 数据处理 → 误差分析 → 实验结论（误差分析不单设节号，引导词"误差分析：①②③"）。数据处理引用"由表中数据得…"而不重抄全表；每步"公式 → 代入 → 结果"，**以计算为主、少写文字说明**：引导语压缩为最短短语（如"厚度平均值："），修约说明、规范依据等解释性文字不进正文（必要说明放误差分析）。最终测量结果用花括号呈现（见硬性要求 3）。误差分析 ①②③ 列点，先系统误差、后偶然误差、再具体到本实验的仪器与操作（如"数错环数""空程"），不写"误差不可避免"式的空话。实验结论 1~3 句，**必须回应实验目的**（目的写"测定 g"，结论就落到 g 的数值与可靠性） |
| 七、原始数据记录 | 整理后的数据表：斜线表头"次数\项目"，行 = 物理量符号+单位，列 = 次序 1…n（n 取 5~10；**逐差型实验 n 必须取偶数**、通常 10 次，见 references\01 §4.3）；多次测量表末尾统计列"平均值\|修正值\|U_A\|U_B\|U_合"；逐差/作图实验加中间计算列（如 D²、(1/T²)、$\Delta x_i = x_{i+5}-x_i$）；做了零点修正的给出"修正值"列；表上方注明仪器精度、零点读数、环境条件 |

硬性要求（每一条都是评分点）：
1. **先写公式，再代入数值**。A 类评定、B 类评定、合成、间接量传递，每一步按"公式 → 代入 → 结果"展开，让老师能逐步复算。
2. 有效数字与修约严格按 `references\01` §2 执行：不确定度取 1~2 位且**只入不舍**，相对不确定度取 2 位只入不舍，**主值末位与不确定度所在位对齐**；中间计算多留 1~2 位，只在最终结果处修约。
3. 结果表示用**花括号形式**（用户定型）：引导句"测量结果为"/"校准结果为"，随后 LaTeX cases 环境两行——第一行 $x = \bar{x} \pm U(\bar{x}) = (\ldots)\ (\text{单位})$，第二行 $E = \dfrac{U(\bar{x})}{\bar{x}} \times 100\% = \ldots$，写法 `$$\begin{cases} … \\ … \end{cases}$$`，前后空行；P>95% 时可不标注 P。
4. 实验有公认值/标准值时，给出百分差 `E_百分差 = |测量值 − 公认值| / 公认值 × 100%`，位数与相对不确定度同口径：**取 2 位有效数字、只入不舍**（如 8.32% → 8.4%）；与相对不确定度分行书写、名称区分，不混用一个 E。
5. 需要作图时按 `references\01` §4.2 执行（坐标纸或软件、分度取 1/2/5 的倍数、轴名+单位+箭头、图线不强求过点、标图名），文字输出给出作图方案与取点计算说明。

### 计算链标准顺序（"数据处理"内部按此展开）

1. 平均值：写出求和式 `x̄ = (x₁+x₂+…+xₙ)/n = …`。
2. 离群值检查：拉依达判据 `|xᵢ − x̄| > 3S_x` 的数据先分析原因再决定剔除，不得不加分析地扔数据。
3. A 类：`u_A = S_x = √[Σ(xᵢ−x̄)²/(n−1)] = …`（本课规定 n=5~10 时直接用测量列标准偏差 S_x 作 A 类不确定度，置信概率 P>95%；**n≥11 时**先算 S_x̄ = S_x/√n，比较 3S_x̄ 与 S_x，取较大者为 u_A，见 references\01 §3.1）。
4. B 类：`u_B = Δ_仪`（本课取分布系数 c=1）。
5. 合成：`U = √(u_A² + u_B²) = …`。
6. 间接量：先 `Ȳ = f(x̄₁, x̄₂, …)`，再取对数求导得传递公式，代入各直接量的 U 求 `U(Y)`。
7. 修约并给出结果表示（第 2、3 条硬性要求）。
8. 有公认值时算百分差。

### 模式二输出示例（节选，来自课件标准例题）

```
## 五、数据处理及实验结论（节选）

由表中数据得平均值：
L̄ = (39.70+39.72+39.68+39.70+39.74+39.72+39.68)/7 = 39.71 mm
A 类不确定度：u_A = S_L = √[Σ(Lᵢ−L̄)²/(7−1)] = 0.0222 mm
B 类不确定度：u_B = Δ_仪 = 0.02 mm（50 分度游标卡尺，本课取 c=1）
合成不确定度：U = √(u_A²+u_B²) = √(0.0222²+0.02²) = 0.0298 ≈ 0.03 mm
测量结果为：
$$\begin{cases} L = \bar{L} \pm U(\bar{L}) = (39.71 \pm 0.03)\ \text{mm} \\ E = \dfrac{U(\bar{L})}{\bar{L}} \times 100\% = 0.076\% \end{cases}$$
```

## 自改进机制（硬性步骤，每次执行，不可省略）

1. 每次输出交付后，主动询问用户："有没有需要纠正或记住的偏好？"
2. 用户给出纠正或确认偏好后，立即按格式 `日期 | 实验名称 | 模式 | 纠正内容` 追加到 `references\反馈记录.md` 的表格末行（模式填"预习"、"数据处理"或"通用"——跨两种模式的全局偏好填"通用"）。**首条写入时先删除表下的占位行"（表为空：暂无记录。）"**，让新行紧接表头分隔行；此后每条紧接上一条。
3. 用户在对话中主动说"记住……"（无论当时是否在生成报告），同样必须写入反馈记录。
4. 每次写入后统计**尚未标注"已合并"的条目数**：**达到 15 条时，无需用户指令，立即自行巩固**（用户随时主动说"巩固"也执行）。巩固步骤：①按主题归并，每条纠正链只取最终定型版本（被后续条目取代的旧条目随之处理）；②输出格式、标签、流程类规则合并进本文件 SKILL.md 对应章节，误差与数据处理规则进 `references\01`，评分要求进 `02`，句式与结构进 `03`；③在每条已合并条目的纠正内容末尾标注"已合并于 <文件名>"，被取代的条目标注"已被第 N 条取代"，条目本身保留作历史；④巩固完成后用几句话告知用户合并了什么。巩固后未合并条目数归零重新累计。
5. 反馈记录因此是本技能的第一优先级依据——这正是第零步每次必读它的原因。
