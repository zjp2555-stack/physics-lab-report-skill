## 1. 基本概念（够用即可）

- **绝对误差**：Δx = x − x₀（x 测量值，x₀ 真值）；**相对误差**：E = Δx/x₀ × 100%。评价测量好坏看相对误差。
- 真值测不出，用**近真值**（多次测量的算术平均值 x̄）代替，它是真值的最佳估计值。
- 误差三类：
  | 类别 | 特征 | 处理 |
  |---|---|---|
  | 系统误差 | 有规律 | 可消除/修正（读数视差、刻度误差、零点误差等） |
  | 随机误差 | 无规律但有统计规律 | 不能消除，用统计方法评定（本文件 §3） |
  | 粗大误差 | 明显超出统计规律 | 判据：拉依达判据 |xᵢ − x̄| > 3S_x 才可剔除，**不得不加分析地扔异常数据** |
- "不给出不确定度的实验结果是无价值的"——模式二的每一步计算都为此服务。
- **精密度**（数据分散程度）、**准确度**（偏离真值程度）、**精确度**（两者兼好）三概念区分。

## 2. 有效数字与修约规则（逐条执行）

### 2.1 有效数字规则

1. 有效数字 = 若干位**可靠数字** + 最后一位**可疑数字**。
2. 直接读数**估读到仪器最小刻度的 1/10 或 1/2**。例：最小格 0.1，读 3.7 ✗；3.70 ✓。
3. 单位换算只动小数点、不动有效位数：2.0 A（2 位）= 2.0×10³ mA（仍 2 位，用科学记数法）。
4. **主值（平均值）末位必须与不确定度所在的位对齐**。例：U = 0.03 mm → L = 39.71 mm ✓；L = 39.7 mm ✗。
5. **不确定度取 1~2 位，相对不确定度取 2 位；与公认值的百分差同为百分数，也取 2 位；尾数舍入只入不舍**（见 2.2 第 6 条）。
6. 反面示例（均错）：I = 1.012 ± 0.123 A（不确定度 3 位）；U = 1.012 ± 0.0004 V（末位不对齐）；T = 9.03 ± 0.01（缺单位）。

### 2.2 修约规则——"四舍六入遇五凑偶"

修约为 n 位：前 n 位为保留数字，看第 n+1 位。

1. **大于 5，上入**：4.509→4.51；5.6678→5.67。
2. **小于 5，下舍**：4.7149999→4.71。
3. **恰好 5 且后面全为 0**（整五）：保留末位是偶数→不变，奇数→进 1。例：9.8450→9.84；9.83500→9.84。
4. **恰好 5 且后面有非 0 数字**：一律进 1。例：3.145001→3.15；9.8051→9.81。
5. 课件练习（修约到 3 位有效数字）：3.145001→3.15（五上入）、3.14498→3.14（五下舍）、4.5076→4.51（五上入）、4.50000→4.50（五下舍）、9.8450→9.84（整五凑偶）、9.83500→9.84（整五凑偶）、9.8051→9.81（五后有数上入）。
6. **不确定度只入不舍**：U = 0.0298 → 0.03（不是 0.029）；相对不确定度 E 同样只入不舍取 **2 位**：0.0755 → 0.076%、0.00886 → 0.89%（不是 0.9%——课件个别例题把 E 印作 1 位，本技能统一按 2 位执行）。

### 2.3 运算中的位数

- 中间计算多保留 1~2 位，只在写最终结果时修约。
- 有效数字运算结果**保留到参与运算各量中最少的位数（或多出 1 位）**。

## 3. 不确定度评定与结果表示（模式二核心）

### 3.1 本课规定速查表

| 量 | 公式 | 说明 |
|---|---|---|
| 平均值 | x̄ = (1/n)·Σᵢ xᵢ | n 次等精度测量的近真值，n 取 5~10 次 |
| 测量列标准偏差 | S_x = √[ Σᵢ(xᵢ − x̄)² / (n−1) ] | 贝塞尔公式 |
| A 类不确定度 | **u_A = 3S_x̄ = S_x** | 本课规定：n=5~10 时直接用 S_x 作 u_A，置信概率 P>95%；**n≥11 时**先算 S_x̄ = S_x/√n，比较 3S_x̄ 与 S_x，**取较大者**为 u_A（课件例 2：11 次测温，3S_x̄=1.59 ℃ < S_x=1.76 ℃，故取 1.8 ℃）；多个独立 A 类分量时 u_A = √(u_A1² + u_A2² + …) |
| B 类不确定度 | **u_B = Δ_仪 / c** | 本课**取 c = 1，即 u_B = Δ_仪**（仅现阶段如此，勿套其他教材的 c 值） |
| 合成不确定度 | **U = √(u_A² + u_B²) = √(S_x² + Δ_仪²)** | 只考虑仪器误差与统计误差的合成 |
| 相对不确定度 | E = U/x̄ × 100% | 结果另起一行给出 |
| 结果表示 | **x = x̄ ± U （单位）**，E = U/x̄ ×100% | P>95% 时可不标注 P；主值末位与 U 对齐 |

符号含义：xᵢ 第 i 次测量值；n 测量次数（5~10）；x̄ 算术平均值（近真值）；S_x 测量列标准偏差（贝塞尔公式）；S_x̄ = S_x/√n 平均值的标准偏差；Δ_仪 仪器误差限（允差，查 §5 表）；c 由误差分布决定的系数（正态分布 c=3，均匀分布 c=√3）。

- 只考虑随机误差的简化表示（n=5~10，无 B 类要求时）：x = x̄ ± 3S_x̄ ≈ x̄ ± S_x（单位），E = S_x/x̄ ×100%，P=99.7%。
- 置信概率背景：误差落在 ±σ、±2σ、±3σ 内的概率为 68.3% / 95.5% / 99.7%。

### 3.2 直接测量完整计算流程（照此顺序写）

1. 列表记录 xᵢ（已扣零点读数）。
2. x̄ = (1/n)Σxᵢ =（写出求和式）= 结果。
3. （需要时）离群值检查：|xᵢ − x̄| > 3S_x 的数据先分析再剔除。
4. u_A = S_x = √[Σ(xᵢ−x̄)²/(n−1)] =（代入）= 结果。
5. u_B = Δ_仪 =（查 §5 表，写明依据）。
6. U = √(u_A² + u_B²) =（代入）= 结果。
7. 修约：U 只入不舍取 1~2 位 → 主值末位与 U 对齐。
8. 写结果 x = x̄ ± U（单位），另起一行 E = U/x̄ ×100% =（取 2 位）。

### 3.3 直接测量标准范例（课件例题，格式照抄）

**例 1（天平测质量，9 次，只考虑随机误差）**：187.9, 187.2, 187.5, 187.1, 187.0, 187.3, 187.8, 187.6, 187.7 g。
- m̄ = (1/9)Σmᵢ = 1687.1/9 = 187.46 ≈ 187.5 g
- S_m = √[Σ(mᵢ−m̄)²/(9−1)] = 0.32 g
- 只入不舍取 1 位：S_m = 0.32 → 0.4 g（主值随之对齐到 0.1 g 位）
- 测量结果：m = m̄ ± S_m = (187.5 ± 0.4) g
- E = S_m/m̄ ×100% = 0.4/187.5 ×100% = 0.2133% → 只入不舍取 2 位 = 0.22%（P>95.5%）

> **数值说明**：课件原页在公式后直接印 S_m=0.4 g、E=0.22%，省略了 0.32→0.4 的只入不舍步骤；直接复算公式得 S_m=0.32 g（python 复核），若用未修约值算则 E=0.32/187.46=0.17%。本技能统一口径：**公式步写实际算出值，随即显式做只入不舍修约，E 用修约后的 U 计算**（例 2 的 0.03/39.71=0.076% 同此口径）；两种口径只差末位，同一份报告内保持一致即可。

**例 2（50 分度游标卡尺测长度，7 次，Δ_仪 = 0.02 mm 均匀分布）**：39.70, 39.72, 39.68, 39.70, 39.74, 39.72, 39.68 mm。
- L̄ = 39.71 mm
- u_A = S_L = √[Σ(Lᵢ−L̄)²/6] = 0.0222 mm
- u_B = Δ_仪 = 0.02 mm（本课取 c=1）
- U = √(0.0222² + 0.02²) = 0.0298 ≈ 0.03 mm（只入不舍）
- 测量结果：L = 39.71 ± 0.03 （mm），E = 0.076%，P>95%

### 3.4 间接测量的不确定度传递

设间接量 Y = f(x₁, x₂, …, xₙ)：

1. **近真值**：Ȳ = f(x̄₁, x̄₂, …, x̄ₙ)——把各直接量的平均值代入函数。
2. **合成不确定度**：
   U(Y) = √[ (∂f/∂x₁)²·u²(x₁) + (∂f/∂x₂)²·u²(x₂) + … ]
   ∂f/∂xᵢ 为 f 对各变量的偏微商，称**误差传递系数**；u(xᵢ) 为各直接量的合成不确定度 U。
3. **相对不确定度**（先取对数再求全微分更方便）：
   E = U/Ȳ ×100% = √[ (∂lnf/∂x₁·dx₁)² + (∂lnf/∂x₂·dx₂)² + … ] ×100%
4. 推导口诀（写进报告的三步）："**取对数 → 求导（全微分）→ 转换为不确定度合成公式**"。
5. 间接量结果表示与直接量相同：Y = Ȳ ± U（单位），E = U/Ȳ ×100%。

**常用函数传递公式表**（U_x 表示 x 的总不确定度）：

| 函数 | 传递公式 |
|---|---|
| N = x ± y | U_N = √(U_x² + U_y²) |
| N = kx | U_N = kU_x；U_N/N = U_x/x |
| N = xy 或 x/y | U_N/N = √( (U_x/x)² + (U_y/y)² ) |
| N = xᵏyᵐ/zⁿ | U_N/N = √( (kU_x/x)² + (mU_y/y)² + (nU_z/z)² )；绝对量 U_N = N × 该相对值 |
| N = ᵏ√x | U_N/N = (1/k)·U_x/x |
| N = sin x | U_N = \|cos x\|·U_x |
| N = ln x | U_N = U_x/x |

> **勘误**：教材表 1-4-2（课件 PPT2·28 原图 s28.png 可核）把 N = xᵏyᵐ/zⁿ 行左端印作 U_N，右端却全是 (kU_x/x)² 类相对量，量纲不符，系印刷错误——按同表 N=ᵏ√x 行的 U_N/N 形式及本文件 §3.4 通用偏导式修正如上表。速查时**勿把该行右端直接当作 U_N**（否则绝对不确定度会算成相对量，如单摆例 U_g 会得出 0.009 而非 0.09 m/s²）。

**标准范例（课件例 4，单摆测 g，g = 4π²l/T²）**
> **数值勘误**：课件原页 l̄=69.00 cm 与印刷结果 ḡ=9.780 m/s² 不自洽——复算 4π²×0.690/1.688² = 9.56 m/s²，而 ḡ=9.780 需 l̄≈0.7059 m（已用 python 复核）。为保持"可复算"，下例把摆长改为与印刷结果自洽的 l̄ = 70.60 cm，其余数值与算法照课件。

l̄ = 70.60 cm、U_l = 0.22 cm；T̄ = 1.688 s、U_T = 0.007 s。
- ḡ = 4π²l̄/T̄² = 4π²×0.7060/1.688² = 9.782 m/s²
- 取对数求全微分：ln g = ln 4π² + ln l − 2ln T → (1/g)dg = (1/l)dl − (2/T)dT
- E = U/ḡ = √[ (U_l/l̄)² + (2U_T/T̄)² ] = √[ (0.22/70.60)² + (2×0.007/1.688)² ] = 0.0089
- U = ḡ×E = 9.782×0.0089 = 0.087 ≈ 0.09 m/s²（只入不舍）
- 测量结果：g = 9.78 ± 0.09 （m/s²），E = U/ḡ ×100% = 0.89%（取 2 位）

### 3.5 不确定度均分原理（模式一选器材时用）

要求 ΔN/N ≤ 给定误差限时，令传递公式各项相等分配：如 V = (π/4)D²h 要求 ΔV/V ≤ 0.5%，则 2ΔD/D ≤ 0.25%、Δh/h ≤ 0.25%，代入粗测值得各量允差，据此选仪器（例：测直径选螺旋测微器、测高度选游标卡尺）。

## 4. 数据处理四种方法

### 4.1 列表法（最常用）
表格要有**表名**（如"表1：伏安法测电阻实验数据"）；表头用"物理量符号+单位"（如 T/s、Δh/cm）；数据列写整齐。其余表头细节见本技能 SKILL.md 模式一"数据记录表格"。

### 4.2 作图法
- **必须用坐标纸或软件（Origin、MATLAB 等）作图，不允许普通白纸自建坐标。**
- 规则：图形位置合适；**坐标轴起点不一定是 0**（取数据区间即可，铺满全纸是反例）；**分度只取 1、2、5 的倍数**；实验点用 +、× 等明确符号。
- 六步：①选分度、定坐标纸大小 → ②画轴（粗实线+箭头，标轴名/符号/单位，标整分格量值）→ ③标实验点 → ④连成直线或光滑曲线（**不强求过每个点**，使图线两侧点分布均匀）→ ⑤标图线特征（在图上取 A、B 两点，用其坐标求斜率/被测量）→ ⑥图下方写图名。
- 曲线改直：把非线性关系变形为线性（如 T²–L、tanθ–1/T²）再作图求参数。

### 4.3 逐差法
- 适用条件：①x 等间距变化；②x 的测量误差可忽略；③测量次数为**偶数**。用于线性关系求斜率/平均增量。
- 隔项差错误做法：(I₂−I₁)+(I₃−I₂)+… 只剩首尾，中间全抵消。
- **分组逐差**（正确做法）：n 个数据对半分组、隔半组相减再平均：
  Δx̄ = (1/(n/2))·[ (x_{n/2+1}−x₁) + (x_{n/2+2}−x₂) + … + (x_n − x_{n/2}) ]
- 优点：用上全部数据，减少计算误差。写报告可注一句"用逐差法处理数据，简单方便且充分利用测量数据"。

### 4.4 最小二乘法（一元线性回归 y = kx + b）
- 使用条件：x 的误差可忽略，只考虑 y 的误差；原理是令偏差平方和 Σvᵢ² 最小。
- k = (x̄·ȳ − x̄ȳ) / (x̄² − x²̄)，b = ȳ − k·x̄
  注意区分"平均值的平方 x̄²"与"平方的平均值 x²̄"（x²̄ = (1/n)Σxᵢ²）。式中 x̄ȳ 表示 (1/n)Σxᵢyᵢ。
- 相关系数：γ = (x̄ȳ − x̄·ȳ) / √[ (x²̄ − x̄²)(ȳ² − ȳ²) ]，|γ|→1 点都在直线上，γ=0 完全分散。
- 求得 k 或 b 后，按 §3.4 传递公式评定其不确定度。

## 5. 常用仪器允差速查（u_B = Δ_仪 用）

| 仪器 | Δ_仪 | 备注 |
|---|---|---|
| 50 分度游标卡尺 | 0.02 mm | 均匀分布（本课仍取 c=1） |
| 螺旋测微器（千分尺） | 0.004 mm（0.0004 cm） | 这是**允差 Δ_仪**；报告表格上方手写的"精度"（如样本写 0.01 mm）是最小分度，不是 Δ_仪，u_B 一律用允差。课件 PPT2·31 单位为 cm，勿看错 |
| 米尺 | 按最小刻度估读 | 正态分布 |
| 读数/测量显微镜 | 0.01 mm | 本课程允差表未单列，按仪器最小分度估取（最小分度 0.01 mm）；如实验室另有规定（铭牌/讲义）从其规定 |
| 物理天平 | 按天平感量 | 正态分布 |
| 秒表 | 按仪器说明 | 正态分布 |

> **辨析："精度"≠允差**：原始数据表上方标注的"仪器精度"通常指最小分度（样本报告写"千分尺的精度 Δx=0.01"即最小分度 0.01 mm）；计算 u_B 用的 Δ_仪 是仪器允差（误差限），两者不是一回事。表注照抄实验室标注，u_B 一律按本表允差取值。
>
> 表中未列的仪器：取说明书/铭牌标注的误差限；确实查不到时在报告"误差分析"中说明并按最小分度估取，注明依据。
