# 02 评分要求与格式规范

> **用途**：动笔前对照的得分点/扣分点/必备要素清单；交稿前按 §6 自检。
> **来源**：《山东大学（威海）普通物理实验 成绩评定及评分标准（学生版）》（2025.05）。

## 1. 总评分构成

| 环节 | 分值 | 对应技能模式 |
|---|---|---|
| 预习报告 | 2 分 | 模式一 |
| 讲解、回答问题、实验操作、数据记录 | 3 分 | 课上环节（数据记录完整条理是本模式一表格设计的目标） |
| 数据处理和实验报告书写 | 5 分 | 模式二 |

- 期末总成绩 = 各实验成绩之和 × 折合系数换算百分制；缺做实验三分之一以上 → 不及格重修。
- 硬性规定：**未完成预习报告者不得进行实验**——模式一输出要及时、完整。

## 2. 预习报告得分清单（模式一对照，2 分）

**必备要素（缺一不可）**
- [ ] 实验目的
- [ ] 实验原理（自行组织语言）
- [ ] 电路图或光路图（电/光学实验必画；技能中给文字画法说明）
- [ ] 结构内容完整、条理清晰

**得分点**
- 实验前认真预习，掌握实验原理、内容与操作要点，提炼出实验要解决的问题。
- **自行组织语言**，简要合理。

**扣分点**
- **完全照抄书本：扣 0.5 分**——原理必须改写，不出现课本原句式。
- 内容缺失、条理不理想、字迹不理想：酌情减分。

## 3. 讲解、操作与数据记录（3 分，与报告相关的要点）

- 原始数据**完整并有条理**地记录——模式一给出的"数据记录表格"要能直接抄进报告纸"七、原始数据记录"。
- 测量结果须经**指导老师签字核对**才算完成；做完整理仪器、经许可再离开。
- 违章操作损坏/丢失仪器：原价赔偿并酌情扣分。

## 4. 数据处理和实验报告得分清单（模式二对照，5 分）

**"良好"档逐条对照（7 条全做到）**
- [ ] 数据处理过程完整、符合要求（公式→代入→结果，可复算）
- [ ] **有效数字记录和运算正确**（按 references\01 §2）
- [ ] **实验结果表达清楚**（x = x̄ ± U（单位）+ E）
- [ ] 实验现象的解释合理
- [ ] **作图规范**（坐标纸/软件、分度 1/2/5、轴名单位箭头、不强求过点、标图名）
- [ ] 有基本的实验分析和讨论
- [ ] 能较好解答部分思考题

**"优秀"档（在良好之上）**
- 分析和讨论透彻，或有独到见解；实验心得表达清晰。

**扣分点（酌情扣分）**
- 报告内容不完整、基本格式不正确。
- **有效数字错误、计算错误、不能正确表达实验结果**。
- 报告过于简单、**数据不列表**、报告不整洁、**作图与教材要求不符**。

## 5. 诚信红线与时限规定（须主动提醒用户）

**诚信红线（触发即 0 分）**

| 行为 | 后果 |
|---|---|
| 造假数据 | 该实验按 0 分 |
| 照抄同学实验报告 | 抄袭者与被抄袭者该实验均记 0 分 |
| 造假或模仿老师签字 | 该门课程成绩按 0 分 |

**时限规定（扣分，不是 0 分）**：报告在实验结束后一周内交到闻天楼 3 楼实验报告箱（按任课教师名字投递）；迟交须一周内补交，**迟交一周扣 1 分，最高扣 4 分**。

> 模式二处理用户给的数据时**只做计算与规范表达，不替用户编造或美化数据**；发现数据明显异常按拉依达判据提请分析，由用户决定取舍。

## 6. 交稿自检清单

**模式一交付前**
1. 前四节（一、实验目的 ~ 四、实验步骤及操作要点）齐全、顺序正确、节次标题为报告纸编号节次？原理、步骤各 ≤600 字？
2. 原理是自己的话，无课本原句式？无"文字画法说明"段落？
3. 关键公式带编号（编号写在引导句里）？包含后续要用的不确定度传递公式？
4. 二、实验仪器照抄当次资料仪器清单原文，无构造细节？
5. 步骤是可执行编号步骤（外层 1.2.3.、内层 ①②③），要点嵌入、末尾注意事项单列？无长篇操作类表格？
6. **字数以工具实测为准**：交付前把原理、步骤两节纯文本（公式按渲染后简写，如 U=ky、fy/fx=Nx/Ny）写入工作目录临时文件，用 mcp-wordcounter 的 analyze_text 统计（口径 = 不含空格字符数），两节均 ≤600 才交付；该工具支持中文路径。

**模式二交付前**
1. 先输出数据审核清单并经用户确认？五、七节齐全（六仅在用户要求时作答）？
2. 每步"公式 → 代入 → 结果"，可复算？计算为主、少写文字说明（引导语为最短短语，无解释性长句）？
3. 不确定度 1~2 位只入不舍、相对不确定度 2 位、主值末位对齐？
4. 最终结果用花括号两行式（cases）？有公认值时给了百分差（2 位只入不舍）？
5. 误差分析 ①②③ 列点且具体到本实验？
6. 结论回应了实验目的？
7. 需要作图的给了规范作图方案？
8. 交付后是否询问"有没有需要纠正或记住的偏好"？
