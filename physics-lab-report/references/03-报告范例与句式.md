# 03 报告范例与句式

> **用途**：组织报告结构与措辞的模板库。结构骨架、各部分句式、3 个完整骨架示例均来自已批阅的真实报告样本，照其风格写。
> **来源**：14 份已批阅手写实验报告扫描件（2025 春，山东大学（威海）物理实验报告纸）逐页分析。
> **格式定型（2026-09-19）**：技能输出已按报告纸七节编号节次组织（`# 实验名称：×××` + `## 一、实验目的` … `## 七、原始数据记录`，Markdown + LaTeX，详见 SKILL.md"输出格式的硬性约定"）。本文件骨架与句式中的"实验名称：""实验目的："等标签行对应新格式的节标题，骨架内容照用；誊写对应关系见下表。

## 一、报告通用结构骨架（固定表单，节次顺序不变）

```
山东大学（威海）物理实验报告
[表头：任课教师/预习成绩/实验成绩/班级/学号/姓名/同组人/时间]
实验题目：____________

一、实验目的
二、实验仪器
三、实验原理
四、实验步骤及操作要点
五、数据处理及实验结论
六、思考及讨论题
七、原始数据记录
教师签字：
```

**输出节次与报告纸栏目的对应关系**（输出已按报告纸节次组织，誊写即归位）：

| 输出节次 | 报告纸栏目 |
|---|---|
| `# 实验名称：×××` | 表头"实验题目"行 |
| 一、实验目的 | 一、实验目的 |
| 二、实验仪器 | 二、实验仪器 |
| 三、实验原理 | 三、实验原理 |
| 四、实验步骤及操作要点 | 四、实验步骤及操作要点（每阶段嵌"要点：…"，末尾注意事项单列） |
| 五、数据处理及实验结论（数据记录→数据处理→误差分析→实验结论，误差分析内嵌不单设节号） | 五、数据处理及实验结论 |
| 七、原始数据记录（表上方注精度/零点/环境） | 七、原始数据记录（表单固定排最后，正文"五"中以"由表中数据得…"引用） |
| 六、思考及讨论题（附加节：仅用户明确要求时作答，追加在固定节次之后） | 六、思考及讨论题，格式"答：…"或 ①②③ 要点，紧跟标题 |

**结构要点**
1. 七个编号节一个不能少、顺序不变；"数据处理及实验结论"是合并节。
2. 仪器精度、零点读数、环境条件（室温等）写在原始数据**表格上方**，不写在"二"里。
3. 误差分析无独立节号，内嵌在"五"中，引导词："误差分析：""分析：①…②…③…"。

## 二、各部分句式模板

### 2.1 实验目的
2~3 条编号句，动词开头，每条一句话。高频句式：「了解……的原理/构造/特点」「掌握……的方法」「学习用……（逐差法等）处理数据」「测定/测量……」「观察/验证……」。典型组合：①了解原理 ②掌握仪器与方法 ③学习数据处理方法。

### 2.2 实验器材
编号罗列 2~5 行，含型号/规格参数。句式例：「游标卡尺、螺旋测微器（千分尺）、测量显微镜、待测圆垫片」「直流电位差计实验仪（含 4.5 V 直流稳压电源、标准电动势、数字检流计、可调变阻器）、导线若干」。复杂装置附文字版构成说明并编号（a.底座 b.换能器 c.支架…）。

### 2.3 实验原理
- 组织：分小标题（1. 2. …）按物理概念切块，"文字叙述+编号公式"交替推进，关键公式右侧编（圈）号。
- 开头惯用句：「把……置于……上，则在……之间形成……」「实验证明，对某一……，当……给定时，……与……成比例，即 …」「……就是利用一个……去抵消另一个……」。
- 推导衔接句：「对……取自然对数得 …」「两边求导数得 …」「转换为不确定度计算公式得 E = …」（不确定度传递三步走）。
- 符号交代句：物理量名+符号+单位逐项列出，如「旋光度 φ：单位"度"；溶液长度 l：单位 dm；浓度 c：单位 g·ml⁻¹」。
- 装置结构（元件构成、光路走向、部件取向）在原理正文叙述中说清即可，**不输出**"××图文字画法说明"段落（用户已定型删去此类段落；报告纸上的电路图/光路图由用户照教材自画）。

### 2.4 实验步骤及操作要点
- 步骤与操作要点**合一输出**（用户定型）：外层「1. 2. 3.」按测法/阶段分块，内层「①②③」列动作，祈使短句；每阶段的易错点以"要点：…"嵌在该阶段末尾，跨阶段通用要点在末尾以「注意事项：①②③…」单列。
- 固定动作句式：「接通电源，开启开关，约 5 min 后……便可使用」「调节……手轮，使其能观察到清晰的……」「沿同一方向缓慢转动微调鼓轮……待条纹稳定后再开始测量（防空程）」「重复测量 6 次并记录」。
- 操作类信息（旋钮/开关预置位置、校准位置等）不列表，写成步骤动作句内的紧凑文字：「电源开关置'关'，辉度反时针旋转到底，……」；**不使用教材面板图的控件编号**（"电源开关①""辉度⑤""时基㉒"这类圈号）——报告纸上无该图例、编号无对照，一律写旋钮/开关名称全称。子动作序号①②③不受此限。

### 2.5 数据处理三范式（模式二"数据处理"按实验类型套用）

**范式一：多组算平均值 → 与公认值比百分差**（单摆/杨氏模量等"代入公式型"）
```
实验数据：ḡ = (10.86+9.89+9.61+11.49+11.21)/5 m/s² = 10.612 m/s²
威海重力加速度公认值为 9.797 m·s⁻²
实验相对误差：E = (10.612−9.797)/9.797 ×100% ≈ 8.32%
```
> 注：规范结果表示以 references\01 §3 为准（x̄ ± U + E）；本范式是样本实际写法，有公认值时两者都要给。**百分差位数**与相对不确定度同口径——取 2 位有效数字、只入不舍，样本的 8.32% 誊写时应写 8.4%（见 SKILL.md 模式二硬性要求 4）；百分差与相对不确定度分行、名称区分。

**范式二：完整不确定度评定**（体积、长度等"直接测量合成型"）
```
V̄ = π(r̄₂²−r̄₁²)·d̄ = 3.1416×(17.205²−9.83²)×2.802 ≈ 1755.122 mm³
(1) 对 V = π(r₂²−r₁²)d 取自然对数得 lnV = lnπ + lnr₂²−lnr₁²… + lnd
(2) 两边求导数得 dV/V = …
(3) 转换为不确定度计算公式得 E = √[U_d²/d² + 4r₂²U_r₂²/(r₂²−r₁²)² + 4r₁²U_r₁²/(r₂²−r₁²)²] = 0.680%
绝对不确定度 U(V̄) = E×V̄ = 11.929 mm³
测量结果：V = (1755.122 ± 11.929) mm³；E = 0.680%
```
（按 references\01 §2 修约后的最终规范式：U 取 2 位只入不舍 11.929→12 mm³，主值末位对齐 1755.122→1755 mm³，E 取 2 位 0.680%→0.68%，即 **V = (1755 ± 12) mm³，E = 0.68%**。上方示例块里的 1755.122±11.929 是修约前的样本原始写法，两者勿混。）

**范式三：逐差法 + 标准差**（牛顿环、声速、迈克尔逊、线膨胀等"等间距逐差型"）
```
由表中数据得：(D_m²−D_n²)̄ = (1/5)(10.945+10.686+10.714+10.564+10.673) = 10.716 mm
标准差 S_d = √{(1/4)Σ[(D_m²−D_n²)ᵢ − (D_m²−D_n²)̄]²} = 0.14 mm
传递：S_R = S_d/[4(m−n)λ] = 0.14/(4×5×589.3×10⁻⁶) = 11.878 mm
R̄ = 10.716/(4×5×589.3×10⁻⁶) = 909.21 mm
E = S_R/R̄ ×100% = 1.3%
```

> 注：范式三只完成 A 类评定（逐差量的标准差及其传递）。按 SKILL.md 模式二硬性要求，逐差型实验（牛顿环/声速/迈克尔逊/线膨胀等）同样必须**补 B 类评定（u_B = Δ_仪，查 references\01 §5 允差表）并合成**（逐差量的 U = √(u_A²+u_B²)，再按同一传递公式传入被测量），最终结果写规范式 X̄ ± U + E，有公认值时另给百分差。样本原稿就缺这一步，照抄会踩"数据处理过程不完整"扣分点。

### 2.6 结果表示写法
1. **花括号形式（默认必须用，用户定型）**：引导句"测量结果为"，随后 LaTeX cases 环境两行——
   `$$\begin{cases} V = \bar{V} \pm U(\bar{V}) = (1755 \pm 12)\ \text{mm}^3 \\ E = \dfrac{U(\bar{V})}{\bar{V}} \times 100\% = 0.68\% \end{cases}$$`
   （U 取 1~2 位只入不舍、主值末位与 U 所在位对齐；E 取 2 位，见 references\01 §2；P>95% 时不标注 P。）
2. 样本中另见：`g = 9.797(1±8.32%) m/s²`（公认值×(1±百分差)；样本原值 8.32%，规范化后写 8.4%）；`综上 R̄ = 909.21 mm，S_R = 11.878，E = 1.3%`（逐项罗列）；`L = 39.71 ± 0.03 （mm）` 另起一行 `E = 0.076%`（逐行式）。三者只作补充行，不能替代花括号规范式。

### 2.7 误差分析句式（①②③列点，先系统、后偶然、再具体）
- 「误差分析：①系统误差：仪器不准或精度不够；②偶然偏差：数错环数；③牛顿环不圆、上有灰尘」
- 「可能原因有：①f 为所测的近似值，可能出现误差；②肉眼读图象时判断可能产生误差；③电压不稳定导致波形不稳定产生误差；④读数不准产生误差」
- 「分析：①节点位置不准确导致测量 f 时产生误差；②肉眼辨识波形不准确产生误差；③测量直径 d 时产生误差」

### 2.8 实验结论句式（1~3 句，回应实验目的）
- 「由图象可知，马吕斯定律验证。」
- 「综上，本次实验达到了示波器测量信号的频率和电压值的目的。」
- 「分析：测量的周期相对误差为 0.0005 s < 0.003 s，属于误差范围内，实验结果较为精确。」
- 「实验结论：本次实验误差较大，可能原因是读数不及时或者按压桌子导致读数有偏差。」

### 2.9 思考及讨论题
**先重复一遍题目再作答**（用户定型，取代旧规"不抄题干"）：题干原文抄出（可加粗），随后「答：…」；回答简短（每题 1~3 句），一句话定性 + 物理原因/关键公式，多条时 ①②③ 编号。

### 2.10 原始数据表格样式
- 左上角斜线表头：`次数\项目`。
- 行表头 = 物理量符号+单位（`T/s`、`Δh/cm`、`g/m·s⁻²`）；列表头 = 次序 1…10。
- 多次测量表末尾固定追加统计列：`平均值 | 修正值 | U_A | U_B | U_合`。
- 表格上方必注：仪器精度与零点读数（如「游标卡尺的精度 Δx=0.02　零点读数 l₀=−0.02　单位：mm」）及环境条件（「室温 26℃」）。
- 表旁/表下注换算公式与常量条件（如「Δh = 2(Y_R − h₀)」「圆筒直径 D：11.618 cm」）。

## 三、完整骨架示例（3 个，覆盖三种典型实验类型）

### 骨架 A：仪器操作测量类——「测量仪器的使用」（完整不确定度评定）
```
实验名称：测量仪器的使用

实验目的：1. 学会游标卡尺、螺旋测微器、测量显微镜的测量原理和使用方法。
2. 掌握游标卡尺读数原理和误差。3. 掌握有效数字的基本概念和测量误差的计算方法。

实验器材：1. 游标卡尺  2. 螺旋测微器（千分尺）  3. 测量显微镜  4. 待测圆垫片（圆筒）

实验原理：
1. 游标卡尺原理（主尺+游标尺，读数 = 主尺整毫米 + 游标对齐格数×精度）……①
2. 螺旋测微器原理（主尺毫米刻度 + 微分筒格数×0.01 mm）……②
3. 体积公式与不确定度传递：V = π(r₂²−r₁²)d ……③；
   对③取对数求导得传递公式 E = U(V)/V = √[U_d²/d² + 4r₂²U_r₂²/(r₂²−r₁²)² + 4r₁²U_r₁²/(r₂²−r₁²)²] ……④

实验步骤：
1. 用游标卡尺测量垫片内径、外径，重复测量 10 次并记录。
2. 用千分尺测量垫片厚度 10 次（读数扣除零点读数）。
3. 用测量显微镜对刻度尺进行校准。

操作要点：①千分尺必须扣除零点读数；②估读到最小分度的 1/10；③卡尺卡紧力度适中防止形变。

数据记录表格：
表1：垫片尺寸测量（次数\项目；行 = 垫片厚度 d/mm、内径 2r₁/mm、外径 2r₂/mm；列 = 次序 1~10；
末尾统计列 平均值|修正值|U_A|U_B|U_合；表上方注「游标卡尺精度 0.02 mm、千分尺精度 0.01 mm、
零点读数、单位：mm」——表注"精度"是仪器最小分度（照实验室标注写）；计算 U_B 用的允差 Δ_仪
按 references\01 §5：卡尺 0.02 mm、千分尺 0.004 mm，两者不是一回事）
```

### 骨架 B：光学干涉 + 逐差法类——「牛顿环」
```
实验名称：牛顿环

实验目的：(1) 通过对牛顿环和劈尖干涉现象的观测，加深对光的波动性的认识。
(2) 掌握用牛顿环测量透镜曲率半径的方法。(3) 学习用逐差法处理数据。

实验器材：读数显微镜、钠光源及附件、牛顿环装置、光学平板玻璃（劈尖）。

实验原理：
1. 把曲率半径很大的平凸透镜凸面置于平板玻璃上，之间形成厚度不均匀的空气薄膜层……
   明环/暗环条件 δ=2e+λ/2=kλ（明，k=1,2,…）、δ=(2k+1)λ/2 即 2e=kλ（暗，k=0,1,2,…）……①②
   （半波损失下环心 e=0 处 δ=λ/2 为暗斑；样本原稿把明暗写反，此处已按物理纠正，勿照抄样本）
   推导 R = (D_m²−D_n²)/[4(m−n)λ] ……③（后续逐差与不确定度评定用）
   光路图文字画法：读数显微镜竖直向下正对牛顿环；45° 半反半透玻璃片将钠光竖直反射入射；
   上下表面反射光干涉形成等厚圆环。
2. 劈尖干涉：θ=λ/(2ΔL)，d=λL/(2l) ……④⑤

实验步骤：
1. 调节牛顿环仪：①放置→②调节目镜使叉丝清晰→③调节 45° 玻璃片→④自下而上缓慢调焦
   直到看清牛顿环→⑤环心移至视场中央。
2. 测量：沿同一方向移动测微鼓轮，从中心向一侧数至第 m 环，逐环记录读数（防回程误差）。

操作要点：①鼓轮只能单向旋转防空程；②叉丝对准环心；③不可数错环数（回查两遍）。

数据记录表格：表：序号 | 环级 m | x₁(左) | x₂(右) | D_m | D_m² | 环差 D_m²−D_n² | 平均值；
表上方注「读数显微镜精度 0.01 mm」。
```

### 骨架 C：振动/共振 + 平均值代入类——「用动态法测杨氏模量」（与标准值比百分差）
```
实验名称：用动态法测杨氏模量

实验目的：1. 了解动态法测量杨氏模量的原理。2. 了解共振（悬挂）测量方法。
3. 掌握差频（示波器李萨如图形）测量方法。

实验器材：动态杨氏模量实验仪（含信号发生器）、示波器、游标卡尺、天平、铜棒、钢棒
（装置构成：a.底座 b.激振换能器 c.支架 d.试棒 e.拾振换能器）。

实验原理：
1. 细棒横振动动力学方程 ∂⁴y/∂x⁴ + (ρS/Y)·∂²y/∂t² = 0 ……①
2. 两端自由棒基频解得 Y = 1.6067·(L³m/d⁴)·f² ……②（代入型主公式）
3. 共振频率判断（悬挂法、李萨如图形法）。

实验步骤：
1. 连接：信号发生器输出接激振换能器，拾振输出接示波器。
2. 试棒悬挂于支架，支点移到 0.224L 与 0.776L（节点）处。
3. 调节信号源频率，振幅最大（或李萨如图形）时判别共振，记录 f。
4. 各测 5 次；测直径 d、长度 L、质量 m。

操作要点：①支点位置准确放在节点；②勿在共振点长时间大功率激振；③直径多点多向测量取平均。

数据记录表格：表1 直径 d/mm × 次序 1~5（钢棒、铜棒各一行）；表2 频率 f/Hz × 次序 1~5；
表下方注「铜棒长度 16.00 cm 质量 37.0 g；钢棒长度 16.00 cm 质量 35.0 g；室温 22℃」。
```

> 三个骨架分别示范：完整不确定度评定（A）、逐差法（B）、平均值代入+百分差（C）。写新实验时选同类骨架套结构，句式按 §二 模板替换内容；数据计算一律按 references\01 执行。
