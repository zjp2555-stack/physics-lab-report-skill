# 讲义库（本仓库为空）

本文件夹用于存放从课程讲义提炼的实验要点文件。技能被点名具体实验时，会先读本目录下的 `索引.md` 查是否命中；命中则以对应讲义文件为该实验**目的、仪器、原理、步骤、注意事项、数据处理要求、思考题**的第一依据，优先于通用模板与教材常识。

原讲义库整理自学校课程配套讲义，为避免传播版权材料，公开仓库不附带任何讲义内容；**本目录为空时技能自动回退到通用模板**（并提醒使用者可提供讲义补入库），功能不受阻。

## 自建讲义库

1. **建 `索引.md`**：一张表维护"实验名称 → 文件名 → 核心物理量/主公式 → 数据处理要点 → 备注"的映射，表头附来源与使用规则说明。技能只依赖其中的文件名映射。
2. **每个实验一个文件**，命名建议 `普物-实验名.md`、`综合-编号-实验名.md`。
3. **文件内固定九节**：一、实验目的｜二、实验仪器｜三、实验原理（公式编号①②③…）｜四、实验内容与步骤｜五、注意事项｜六、数据处理要求｜七、思考题｜八、原始数据表格样式｜九、提炼缺口。
4. **忠实原则**：讲义没给的内容一律写"讲义未给出"，不编造；讲义印刷疑误按原样记录并加注，输出时采用修正形式。第九节列出存疑处，便于回查原始讲义。
